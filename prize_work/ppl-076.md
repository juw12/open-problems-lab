## Exact statement

> **Erdős (1974, #3).** Let $A\subseteq\mathbb{N}$. If
> $$\sum_{n\in A}\frac{1}{n}=\infty,$$
> then must $A$ contain arbitrarily long arithmetic progressions?

Equivalently, as the page puts it: is every $A$ with divergent reciprocal sum forced to contain a $k$-term arithmetic progression, for **every** $k\ge 3$?

## What is known

The problem is "essentially asking for good bounds on $r_k(N)$", where $r_k(N)$ is the largest size of a $k$-term-AP-free subset of $\{1,\dots,N\}$. The reduction (derived and checked numerically below): if $A$ is $k$-AP-free then $A(n):=\sum_{j\le n}a_j\le r_k(n)$, and by partial summation
$$\sum_{n\in A}\frac1n \ \le\ \lim_{N\to\infty}\Big[\frac{r_k(N)}{N}+\int_1^N\frac{r_k(x)}{x^2}\,dx\Big].$$
So the reciprocal sum converges **iff** $\displaystyle\int_1^\infty \frac{r_k(x)}{x^2}\,dx<\infty$, i.e. if $r_k(x)\ll x\,g(x)$ with $\int g(x)\,dx/x<\infty$. The threshold sits at $g\sim1/(\log x\,\log\log x)$:

| Candidate bound $r_k(N)$ | $\int r_k(x)/x^2\,dx$ | Solves #3? |
|---|---|---|
| $N/(\log N)^C$ | $=\int dx/(x\log^C x)$ | yes **iff** $C>1$ |
| $N/((\log N)(\log\log N)^2)$ | $=\int dv/v^2$ | **yes** (sufficient, matches page) |
| $N/((\log N)\log\log N)$ | $=\int dv/v$ | no (diverges) |
| $N\exp\!\big(-(\log N)^{c_k}\big)$ | $=\int_0^\infty e^{-u^{c_k}}du=\tfrac1{c_k}\Gamma(1/c_k)$ | **yes** (any $c_k>0$) |

Known bounds on $r_k(N)$ (as cited on the page and in ppl-123 / Erdős #142):

| Ref | Bound | Scope |
|---|---|---|
| Bloom–Sisask [BlSi20] | broke the $\log$ barrier | $k=3$ |
| Kelley–Meka [KeMe23] | $r_3(N)\ll N\exp(-c(\log N)^{1/12})$ | $k=3$ |
| Green–Tao [GrTa17] | $r_4(N)\ll N/(\log N)^c$ | $k=4$ |
| Gowers [Go01] | $r_k(N)\ll N/(\log\log N)^{c_k}$ | all $k$ |
| Leng–Sah–Sawhney [LSS24] | $r_k(N)\ll N/\exp((\log\log N)^{c_k})$ | $k\ge5$ (all $k$) |
| Erdős [Er81] (stronger conjecture) | $r_k(N)\ll_C N/(\log N)^C$ for every $C>0$ | page says "**now known for all $k\ge3$**" (see #140) |

The strongest pre-2026 bounds already **exceed** the sufficiency threshold for some $k$ (e.g. Kelley–Meka for $k=3$), but a **uniform** bound for **all** $k\ge3$ is what #3 needs. The 2026 development below is precisely such a uniform bound.

### Method

The computation does **one verifiable step** on the mathematical core of the problem — the reduction from #3 to the convergence of $\int r_k(x)/x^2\,dx$ — and reproduces published constants as gates. It does **not** re-prove or verify the OpenAI preprint's $r_k$ bound.

- **Part A — Abel / partial-summation identity (exact, on a discrete set).** For $a_n=1_{n\in A}$ and $A(N)=\sum_{n\le N}a_n$:
  $$\sum_{n=1}^N \frac{a_n}{n} \;=\; \frac{A(N)}{N} \;+\; \sum_{n=1}^{N-1}\frac{A(n)}{n(n+1)}.$$
  This is the identity used to bound $\sum_{n\in A}1/n$ by $r_k$ (above).
  - **A1 (full set $A=\{1,\dots,N\}$, $N=10^6$):** both sides equal $H_N$, so the identity must hold to rounding, and $H_N$ must match the published asymptotic $\log N+\gamma+\tfrac1{2N}-\tfrac1{12N^2}$ to $O(1/N^4)$. Gate: identity error $<10^{-12}$ **and** asymptotic error $<10^{-9}$.
  - **A2 (sparse 3-AP-free set):** $A$ = the OEIS **A003002** record 3-AP-free set of size 15 in $\{1,\dots,40\}$: $\{1,2,4,5,10,11,13,14,28,29,31,32,37,38,40\}$. Gate: (i) the set is verified $k$-AP-free for $k=3$ (no three distinct members in AP), (ii) the Abel identity holds to $10^{-13}$, (iii) the computed reciprocal sum is reported and checked to be **finite and small** (a 3-AP-free set has convergent reciprocal sum — consistent with the reduction).
- **Part B — the claimed quasipolynomial bound's integral (the convergence question).** For $r_k(x)\ll x\,e^{-(\log x)^{c_k}}$, set $u=\log x$: $\int_1^\infty e^{-(\log x)^{c_k}}dx/x=\int_0^\infty e^{-u^{c_k}}du=\tfrac1{c_k}\Gamma(1/c_k)<\infty$ for every $c_k>0$. Gate: numerically evaluate the integral by composite Simpson on $[0,\,L]$ (with the tail $L=\max(1,\lceil(30/c_k)^{1/c_k}\rceil$ giving $e^{-30}\approx9.4\times10^{-14}$) and compare against the closed form $\tfrac1{c_k}\Gamma(1/c_k)$ for $c_k\in\{0.5,1,2,3\}$; require relative error $<10^{-9}$. Also report the discrete series $\sum_{n\ge2}e^{-(\log n)^{c_k}}/n$ to show the convergence on the integer lattice.
