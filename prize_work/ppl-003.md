**Prize:** $250 (open, "exact"). **Catalog status: OPEN (verified open, checked 2026-07-26).**

## Exact statement
> Schoenberg proved that for every c ∈ [0,1] the density
> `f(c) = dens{ n ∈ ℕ : φ(n) < c·n }` exists.
> Is it true that there are **no** x such that `f'(x)` exists and is positive?
