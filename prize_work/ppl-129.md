# PPL 129 — Erdős Problem #710

## Statement

Let f(n) be the minimal L such that in the interval (n, n+L) there exist distinct integers
a_1, a_2, …, a_n with k | a_k for all 1 ≤ k ≤ n. Obtain an asymptotic formula for f(n).

## Prize

- ₹2000 (≈ $78, 1992 conversion) — listed on erdosproblems.com/710.
- Open since 1980 (Erdős–Pomerance).

## Status

**STILL OPEN.** No verified proof exists. An AI-assisted proof claim (David Turturean,
2026-09-23, GPT-6-Astra Pro) asserts f(n) ~ (√2/e)·n·√(log n), but it is not peer-reviewed
and erdosproblems.com explicitly states "no guarantee of proof correctness."

Catalog (prizeproblems.org PPL 129) is **CORRECT**.

## What Is Known

### Erdős–Pomerance [ErPo80, 1980]

- **Lower bound**: f(n) ≥ (2/√e + o(1))·n·√(log n / log log n)
  = (1.21306…+o(1))·n·√(log n / log log n)
  (Note: 2/√e = 1.21306…; an earlier version of this dossier misprinted it as 0.797.)
- **Upper bound**: f(n) ≤ (1.7398…+o(1))·n·√(log n)
  where 1.7398 = √r/(1−r) and e^{−r} = r (r ≈ 0.5671).
- **Example**: f(10) ≤ 15, achieved by a_k = [11,22,21,16,15,12,14,24,18,20]
  (all distinct, all in (10, 25], k | a_k for each k).

### AI-assisted proof claim (2026-09-23, UNVERIFIED)

David Turturean claims f(n) ~ (√2/e)·n·√(log n) ≈ 0.5203·n·√(log n).
Manuscript on Overleaf (link on erdosproblems.com/710). Not peer-reviewed.
The implied constant √2/e ≈ 0.5203 is below the EP lower-bound constant 2/√e ≈ 1.2131
when expressed in the same scaling, but the scalings differ: the EP lower bound has
√(log n / log log n) while the claim has √(log n), so the comparison is not direct.

### Lean formalization

github.com/google-deepmind/formal-conjectures, `FormalConjectures/ErdosProblems/710.lean`.
Defines f(n) via `sInf`. Contains:
- Verified theorem: f(10) ≤ 15 (constructive proof via the ErPo80 example).
- `sorry` theorems: EP lower bound, EP upper bound, and the main asymptotic.

**Interval convention note**: ErPo80 defines f as the smallest m with a solution in (n, m],
while the prize problems statement uses (n, n+L). The two are related by f_erpom(n) = n + L.

**Idea card**: fit ratio(n) = f(n)/(n·√(log n)) = A + B/√(loglog n) on n=100..5000 and

optimized HK was caught by the gate and fixed; the buggy `fit_data.json` is superseded.)

**Main fit** (least squares, numpy and a hand-rolled normal-equation solve agree to 5 dp):

|-------|------|-------------|-----|------|
| M1 card  | A + B/√(loglog n) | A=0.41581, B=0.39749 | 0.7062 | -246.86 |
| M2 const | A                   | A=0.70244             | —     | -215.79 |
| M3 EP    | B/√(loglog n) (A=0) | B=0.97258             | **-0.776** | -200.28 |
| M4 alt   | C + D/√(log n)      | C=0.54940, D=0.40147  | 0.7085 | -247.07 |
| M5 alt   | C + D/(loglog n)    | C=0.56247, D=0.26846  | 0.7034 | -246.61 |

**Findings**

1. **Kill test fires.** The fitted intercept A = 0.41581 is below 0.50 (outside the
   plausibility band [0.50, 0.75]) and below the Turturean constant √2/e = 0.52026.
2. **The Turturean claim f(n) ~ (√2/e)·n·√(log n) is not supported by the data.**
   The observed ratio is essentially flat at ≈ 0.691 over n = 1000..5000
   (0.69133 → 0.69085), i.e. ~33% above 0.5203, with no convergence toward it on this
   range. The 1/√(loglog n) transient that would carry the model down to 0.5203 has not
   started to shrink by n = 5000.
3. **The EP lower-bound asymptotic form is ruled out.** Forcing A = 0 (the pure
   2/√e·n·√(log n/loglog n) shape) gives R² = -0.776 — *worse than a horizontal line* —
   so the data does not decay as 1/√(loglog n) with constant 2/√e = 1.2131.
   (The fitted M1 B = 0.39749 is also far below 1.2131, and far below the misprinted 0.797.)
4. **The correction form is not identifiable.** M1 (1/√loglog), M4 (1/√log) and
   M5 (1/loglog) fit within 0.5 AIC of each other; the data over n = 100..5000 cannot
   distinguish them. All three put the asymptotic constant between 0.42 (fast 1/√loglog
   decay) and 0.56 (slow 1/loglog decay), with the Turturean 0.5203 sitting mid-range.
5. **Best working description** of the data on this range: f(n) ≈ 0.70·n·√(log n) with a
   small, slowly decaying positive correction.

**Verdict**: clean **negative** for the card's hypothesis (the data does not support
√2/e = 0.5203 on n ≤ 5000, and the EP 1/√(loglog n) form is excluded). The fit was
performed and the claim tested decisively; the card's kill criterion (A ∈ [0.50,0.75])
was not met.

**Method**: for each p in [0.2, 1.5] (step 0.005, 261 values) run the exact 2-parameter OLS of
y_n = f(n)/(n·√(ln n)) on [1, (ln ln n)^−p] (linear in C, D for fixed p); scan p for best R²/AIC/BIC
and C-sensitivity. AIC = N·ln(SSE/N) + 2k, BIC = N·ln(SSE/N) + k·ln N (k = 2). Independent verifier:
scipy.optimize.least_squares doing a JOINT nonlinear fit over (C, D, p) with multi-start and no grid
(a genuinely different optimizer, same ratio-space SSE objective).

**Result** — the best fit sits at the **grid boundary p = 0.2** (identical by R², AIC and BIC):

| p | C | D | R² | AIC | BIC |
|------|---------|---------|---------|---------|---------|
| 0.200 | −0.02438 | 0.82865 | **0.70747** | −246.979 | −244.387 |
| 1.500 | 0.61130 | 0.24110 | 0.70001 | −246.299 | −243.707 |

**The p-scan is a flat valley.** R²(p) falls monotonically 0.70747 (p=0.2) → 0.70001 (p=1.5); AIC(p)
rises monotonically −246.979 → −246.299, a **span of only 0.68 AIC units** across the whole range, so
**every p in [0.2, 1.5] is within 2 AIC of the best**. As p grows, C rises monotonically while D falls
(pure C/D trade-off at nearly constant fit quality):

| p | C | D | R² | | p | C | D | R² |
|------|--------|--------|---------|-|------|--------|--------|---------|
| 0.20 | −0.0244 | 0.8287 | 0.70747 | | 0.775 | 0.51991 | 0.30266 | 0.70474 |
| 0.50 | 0.41581 | 0.39749 | 0.70616 | | 1.00 | 0.56247 | 0.26846 | 0.70342 |
| 0.70 | 0.49963 | 0.32031 | 0.70514 | | 1.50 | 0.61130 | 0.24110 | 0.70001 |

**Findings**

1. **Kill test fires (first clause): best R² = 0.70747 < 0.72.** Freeing p improves R² by only
   +0.0013 over job-36's fixed p = 0.5 (0.70616 → 0.70747) — statistically nothing. (The second
   clause, C-shift > 0.05 over a 0.1 p-window, does *not* fire — max 0.018 — but that is an artifact
   of the fine 0.005 grid step; the meaningful C-range is far larger, see 3.)
2. **The optimum is a boundary artifact (p = 0.2), not an interior point** — a red flag that p is not
   data-determined (the likelihood wants even lower p). The near-flat AIC(p) (span 0.68 over
   p ∈ [0.2,1.5]) means the data carries essentially zero information to localize p.
3. **C is unidentifiable.** The credible-AIC region {AIC(p) − min ≤ 2} is the *entire* grid; C sweeps
   [−0.024, 0.611] across it (span 0.636), with central dC/dp ≈ 1.47 near the boundary. Freeing p does
   NOT sharpen C — it exposes the full degenerate band that job 36's fixed p=0.5 had hidden.
4. **The Turturean constant 0.5203 is not distinguishable.** C(p) passes through 0.5203 at
   p = 0.775 (C = 0.51991, |gap| = 0.00035), but that p is no better than any other p in [0.2, 1.5]
   (all within 2 AIC). 0.5203 is one value inside the unidentifiable band [−0.024, 0.611]; the
   27-point grid neither confirms nor refutes it.
5. **Root cause / diagnosis.** Over ln ln n ∈ [1.53, 2.14] the curves (ln ln n)^−p for p ∈ [0, 1.5]
   are all nearly *linear* in ln ln n, so the data pin down only a roughly linear-in-ln ln n trend,
   not which power generated it. The unconstrained scipy run confirms this: allowing p < 0.2, the fit
   runs to p = 0.086, C = −1.0, D = 1.801 (R² = 0.70790), i.e. the p→0, C→−∞, D→+∞ degenerate
   direction (toward a −c·ln(ln ln n) transient), beating the in-range fit by only 0.0004 in R².
   Resolving p would need ln ln n to vary by orders of magnitude — n out to ~10^60+, infeasible for
   exact f(n).

**Independent verification (step 5)**: scipy joint least-squares (multi-start, p ∈ [0.2, 1.5])
reproduces the grid+OLS optimum to <1e-5: C = −0.02438, D = 0.82865, p = 0.20000, R² = 0.707469,
SSE = 0.0024795351 vs OLS SSE = 0.0024795390 (|ΔC| = 0.0, SSE rel-diff 1.6e-6). **PASS** — the card's
verifier (C agreement within 0.02 between optimizers) is met exactly. The two optimizers agree on fit
quality (SSE/R²) to 6 digits; the unconstrained run separately shows C itself is not a well-defined
quantity (it sits on a flat valley).

**Classification (step 6): negative.** The free decay-exponent form is **unidentifiable on 27 points**:
best R² = 0.70747 < 0.72, the best fit is a boundary artifact (p = 0.2), and C is an unidentifiable
band [−0.024, 0.611] within 2 AIC. This extends job-36's "M1/M4/M5 within 0.5 AIC" to a fully free p
and quantifies it: the AIC(p) span is only 0.68 over all of [0.2, 1.5], and the Turturean 0.5203 is
